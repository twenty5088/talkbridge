# TalkBridge 實機測試計畫

模擬器測不到真正的麥克風、語音辨識、Apple 翻譯和藍牙路由，這些只能在 iPhone 上驗證。請逐項操作，把結果填進「實際結果」和「Pass/Fail」。

- 測試裝置：iPhone 17 系列，iOS 26.6.2
- 耳機：一般藍牙耳機（沒有 AirPods）。有 AirPods 的話可以加測，畫面應顯示「AirPods」。
- 測試句子一律用下面的人工示例句，不要用真實個資。

| 語言 | 對方說（示例） | 太太說（示例） |
|---|---|---|
| English | Where is the train station? | 請問車站在哪裡？ |
| Bahasa Indonesia | Di mana stasiun kereta? | 這個多少錢？ |
| ไทย | สถานีรถไฟอยู่ที่ไหน | 我想要一杯水。 |
| 日本語 | 駅はどこですか？ | 洗手間在哪裡？ |
| 한국어 | 기차역이 어디예요? | 謝謝你的幫忙。 |

記錄方式：每項都寫實際看到的狀態文字、聲音從哪裡出來、等了幾秒。失敗的請截圖。
