# TalkBridge v2：按鈕指定下一句＋使用情境總檢查 設計文件

日期：2026-11-07　前一版設計：`2026-11-07-talkbridge-design.md`（本文件只寫改變的部分，其餘照舊）
標記：【Kevin 決定】＝Kevin 原話或明確選擇；【Claude 判斷】＝我替 Kevin 做的決定，Kevin 可推翻。

## 0. 這份文件的演變
- 第一版提議「兩個辨識器同時聽、自動判斷語言」，並做了拋棄式實測畫面。
- 【Kevin 決定】（同日）**不做自動判斷**，改成由使用者按按鈕指定下一句是誰說。實測畫面已撤掉（commit e881b22 revert）。以下是 Kevin 核准的版本。

## 1. 為什麼要改
- 【Kevin 決定】自動輪流寫死一人一句；Kevin 常連講兩三句中文，對方也可能說到一半就被停頓切斷。
- 【Kevin 決定】要求把各種使用情境想清楚、寫成測試，把找到的不方便處一起修掉（第 3 節）。

## 2. 按鈕指定「下一句換誰說」

### 2.1 規則
- 【Kevin 決定】預設照舊：自動輪流＝一人一句；手動模式照舊。
- 【Kevin 決定】太太說中文 → 翻成外語 → 倒數／播放中，太太按「我說中文」→ **這一句照常播完**，播完後麥克風聽中文（不換對方）。對方那邊相同：中文翻譯或播放中按「對方說話」→ 中文照常播完，再繼續聽對方。
- 【Kevin 決定】在翻譯、倒數或播放期間按按鈕，**不中斷**目前這句，只記住「下一句換誰說」；播完約 0.3 秒（原本的麥克風保護間隔）後開始聽指定的人。
- 【Claude 判斷】前後兩段各自翻譯，不合併重翻。
- 【Claude 判斷】各狀態下按「對方說話／我說中文」的行為：

| 目前狀態 | 按同一方 | 按另一方 |
|---|---|---|
| 待機、錯誤、語言未準備、需要權限 | 開始聽這一方（照舊） | 開始聽另一方（照舊） |
| 正在聆聽 | 這句說完了，送出（照舊） | 放棄這句，改聽另一方（照舊） |
| 正在辨識、正在翻譯 | 記住：播完後再聽同一方 | 記住：播完後聽另一方 |
| 倒數／待播（給對方的外語） | 記住 | 記住（**改變**：原本按「我說中文」＝丟掉這句重錄；重錄改由「重新錄音」按鈕） |
| 正在播放 | 記住（**改變**：原本＝停止播放） | 記住（**改變**：同左） |

- 再按另一方的按鈕＝改成記住另一方（以最後按的為準）。
- 畫面顯示「下一句：我說中文」或「下一句：對方說話」。
- 【Claude 判斷】按「全部停止」、按「停止播放」、發生錯誤 → 清掉記住的下一句。手動模式也適用同樣規則（播完後聽記住的那一方）。
- 【Claude 判斷】待播但**沒有在倒數**（先確認再播、取消了倒數、停止了播放、或手機沒有該語言語音）時按按鈕＝照舊立刻開始新的一輪，不記住；否則沒有語音時會卡在待播。

## 3. 使用情境總檢查（找到的問題與修法）
每一項都要先寫會失敗的測試，再修到通過。

| # | 情境 | 現在會怎樣 | 修法 |
|---|---|---|---|
| P1 | 太太連講兩句中文（Kevin 回報） | 第二句被當成英文辨識 | 第 2 節按鈕指定 |
| P2 | 對方說到一半被停頓切斷、或超過 30 秒被切段 | 第二段被當成中文 | 第 2 節按鈕指定 |
| P3 | **對話中螢幕自動鎖定** | 閒置約 30 秒～1 分鐘鎖螢幕 → App 進背景 → 對話被強制停止 | 對話進行中（非待機、或自動輪流進行中、或有記住的下一句）不讓螢幕自動鎖定；回到待機後恢復 |
| P4 | 自動輪流中聽到雜音、辨識出空白 | 顯示「沒有聽到內容」後自動輪流**靜靜停住**，畫面還寫輪到誰 | 自動輪流時忽略空白結果，繼續聽同一方 |
| P5 | 自動輪流中想重播某一句 | 一直在聆聽，卡片「重播」按了沒反應 | 聆聽中按重播＝停止聆聽 → 播放 → 播完繼續聽原本那一方 |
| P6 | 自動輪流 15 秒沒人說話 | 自動暫停；對方看畫面、想一下就超過 | 【Claude 判斷】自動輪流改成 60 秒沒聲音才暫停；手動模式維持 15 秒 |
| P7 | 翻譯失敗按「再試一次」 | 回到待機，要整句重講 | 「再試一次」用同一句文字重新翻譯並接著播放 |
| P8 | 喇叭播出的譯文殘響被麥克風收到 | 播完英文後換聽對方（英文），殘響可能被當成對方說的話，又翻回中文 | 播放後的第一句，若文字和剛播出的譯文幾乎一樣就丟掉、繼續聽 |
| P9 | 對話卡片越來越多 | 新卡片不會自動捲過去 | 有新卡片時自動捲到最新一張 |
| P10 | 翻譯、倒數或播放時開口說話 | 麥克風關著，話被漏掉，使用者不知道 | 狀態區明確顯示「現在可以說話：中文／English…」（聆聽中）或「請稍等，麥克風已關閉」（忙碌中） |
| P11 | 換語言、全部停止、來電、耳機斷線、切到背景時有記住的下一句 | 新功能 | 都要清掉記住的下一句，不會在之後突然開麥克風 |

## 4. 不做的事
- 不做自動判斷語言、不用聲紋分辨誰在說話。
- 不處理兩人同時說話。
- 播放時不收音（不變）；不存任何錄音（不變）。

## 5. 只能在實機確認的事（加進實機測試計畫）
- 播放中按按鈕的實際手感：播完到開麥克風的間隔是否順。
- 螢幕不自動鎖定是否生效、回待機後是否恢復。
- 殘響過濾在實際音量下是否足夠；有沒有把對方真的說的話誤丟。

## 6. 留給實作者決定的
- 「下一句：…」與麥克風提示的顯示位置與樣式（要符合原本的無障礙規則：文字＋圖示、Dynamic Type）。
- 殘響比對的相似度算法與門檻（集中在設定檔）。
